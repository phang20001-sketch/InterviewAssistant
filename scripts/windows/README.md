# Windows 使用说明

## 安装包状态

Windows 安装包暂未发布，`installers/` 目录和开发脚本已保留，等待后续补充构建和验证。

## 安装与启动

安装包发布后，可按文件类型操作：

| 文件                        | 使用方法                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------ |
| `InterviewStudio-Setup.exe` | 双击安装，之后从开始菜单打开应用。                                                   |
| 名称包含 `win32-x64` 的 ZIP | 右键选择“全部解压”，打开解压目录中的 `InterviewStudio.exe`。请保留同目录的全部文件。 |

直接使用应用无需安装 Node.js，也不用运行 `.cmd` 脚本。安装包将通过 Releases 提供，不放入 Git 源码仓库。

## 开发与打包

安装项目要求的 Node.js，在项目根目录执行 `npm ci`，之后可双击：

- `start.cmd`：启动开发应用。
- `build.cmd`：生成 Windows 安装包和 ZIP，并复制到当前目录的 `installers/` 文件夹。
