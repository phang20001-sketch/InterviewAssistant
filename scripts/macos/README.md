# Mac 用户使用说明

## 只想使用软件

不需要 Node.js、npm 或开发工具，也不用运行旁边的 `.command` 脚本。

1. 向维护者获取 Mac 应用 ZIP，或在维护者发布后从仓库 Releases 下载。如果拿到的是完整分发文件夹，应用包在本文件夹的 `installers/` 中。
2. Apple 芯片的 Mac 双击解压名称包含 `darwin-arm64` 的 ZIP。这个 ZIP 本身就是应用分发包，无需下载项目源码。
3. 把解压后的 `Interview Studio.app` 拖入 Finder 的“应用程序”文件夹。
4. 从“应用程序”打开 Interview Studio；以后直接打开这个应用。
5. 首次进入可使用演示模式；要使用真实 AI，在“模型与设置”配置模型地址、名称和 API Key。

仓库尚未发布 Releases；目前可向维护者获取本地生成的应用包。当前提供 Apple 芯片版，不能将它当作 Intel 版使用。Intel Mac 需要另行构建 `darwin-x64` 包。

### 第一次打开与权限

当前应用尚未完成 Developer ID 签名及 Apple 公证。仅对可信来源的软件，在系统允许时通过“系统设置 → 隐私与安全性 → 仍要打开”确认；不要关闭系统安全机制。如果系统提示损坏、无法验证或没有允许入口，联系维护者提供签名公证版本。

- 麦克风：首次录音允许授权。若拒绝，进入“系统设置 → 隐私与安全性 → 麦克风”开启 Interview Studio。
- 截图：允许“屏幕与系统音频录制”（部分系统称“屏幕录制”）。修改后按 `⌘ Q` 完全退出再重新打开。
- 关闭窗口后应用仍运行，点击 Dock 图标重开；`⌘ Q` 完全退出。
- 录音只采集麦克风。内容保护无法保证窗口不被其他录屏软件捕获。

## 需要开发或自行打包

先安装项目要求的 Node.js，在项目根目录执行 `npm ci`。

- `start.command`：启动开发应用。
- `build.command`：构建 Mac 应用 ZIP；构建成功后自动复制到本文件夹的 `installers/`。

安装包是生成文件，不提交到 Git 源码仓库。从 GitHub 下载源码时通常没有 `installers/`；普通用户应下载维护者提供的分发包或 Releases 附件。不要把“下载源码 ZIP”当作应用安装包。
